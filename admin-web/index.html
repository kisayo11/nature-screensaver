    구글 드라이브 원클릭 자동 배포 세팅 가이드

    1단계

    Google Apps Script 프로젝트 생성 (1분 소요)

    1. Google Apps Script(script.google.com) 에 접속하여 로그인 후 [새 프로젝트]를 클릭합니다.
    2. 기존 코드를 모두 지우고 아래의 스크립트 코드를 붙여넣습니다:
    Google Apps Script (Code.gs) 
    function doPost(e) {
  try {
    // 구글 드라이브의 config.json 파일 ID를 아래 입력하세요.
    // 예: https://drive.google.com/file/d/1A2B3C4D5E.../view 이라면 1A2B3C4D5E... 가 FILE_ID입니다.
    var TARGET_FILE_ID = "여기에_구글드라이브_CONFIG_JSON_파일ID_입력";
    
    var jsonString = e.postData.contents;
    var file = DriveApp.getFileById(TARGET_FILE_ID);
    file.setContent(jsonString);
    
    return ContentService.createTextOutput(JSON.stringify({ status: "success", message: "config.json updated successfully" }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({ status: "error", message: err.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
    2단계

    웹 앱으로 배포하기

    1. 우측 상단 [배포] ➔ [새 배포] 클릭 후 톱니바퀴 아이콘에서 [웹 앱]을 선택합니다.
    2. 설정:
      • 다음 사용자 권한으로 실행: 나(내 이메일)
      • 액세스 권한 있는 사용자: 모든 사용자(Anyone)
    3. [배포] 클릭 ➔ 구글 권한 승인 창에서 [권한 검토] ➔ [고급] ➔ [안전하지 않음으로 이동] ➔ [허용]을 진행합니다.
    4. 배포 완료 후 표시되는 웹 앱 URL (https://script.google.com/macros/s/.../exec)을 복사합니다.
    3단계

    관리자 웹에 연동하기

    복사한 URL을 어드민 상단 [설정]의 Google Apps Script 연동 URL 칸에 붙여넣으면 완료됩니다! 이제 [구글 드라이브에 배포] 버튼을 누를 때마다 구글 드라이브의 config.json이 자동으로 최신화됩니다.

    🕒

    배포 이력 관리 및 원클릭 롤백

    과거에 배포했던 슬라이드 설정 스냅샷 목록입니다. 원하는 버전의 [이 버전으로 복원] 버튼을 누르면 즉시 해당 슬라이드 구성으로 롤백됩니다.
