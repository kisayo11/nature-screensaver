    아래 버튼을 누르면 repo 권한이 자동 체크된 토큰 생성 페이지가 새 탭으로 바로 열립니다. (GitHub 로그인이 필요합니다.)

    옵션 확인 및 토큰 발급

    • Select scopes: 맨 위의 repo (Full control of private repositories)가 체크되어 있는지 확인
    • 화면 맨 아래의 초록색 [Generate token] 버튼을 클릭합니다.

    설치 프로그램 다운로드 (.exe)
    ⏱️ 시간설정 (.cmd) 📦 ZIP
    1단계: 다운로드 & 실행

    파일 실행 (더블 클릭)

    받은 NatureScreensaverSetup.exe를 실행합니다.
    (SmartScreen 파란 창이 뜨면 [추가 정보] → [실행])

    2단계: 원클릭 설치

    마법사 [설치] 클릭

    설치 마법사에서 [설치]만 누르면 화면보호기 등록 및 필수 파일 복사가 10초 내로 끝납니다.

    3단계: 자동 가동

    3분 대기 자동 설정

    병원 평가인증 표준인 3분(180초)으로 자동 등록되며, 클라우드와 실시간 자동 동기화됩니다.

    ⚙️ 다운로드 링크 출처 설정 (GitHub Releases / 구글 드라이브 / 원내 NAS 링크 변경)

    기본적으로 GitHub Releases 글로벌 초고속 CDN을 통해 0.2초 만에 즉시 다운로드됩니다. 필요 시 원내 NAS나 구글 드라이브 링크로 교체할 수 있습니다.

    💡 다운로드 링크 옵션:
    1. GitHub Releases (기본 권장): 바이러스 경고창이나 다운로드 한도 제한 없이 전 병원 PC에서 0.2초 즉시 다운로드됩니다.
    2. 원내 NAS 공유 링크: 시놀로지/QNAP 파일 스테이션에서 .exe 파일 우클릭 → [공유 / 링크 생성] 시 '비밀번호 보호' 체크 해제 후 생성된 링크를 넣으면 로그인 없이 원내 기가비트 초고속 다운로드가 가능합니다.
    3. 구글 드라이브: .exe 파일의 공유 링크를 넣으면 바이러스 경고창을 자동 우회하는 직다운로드 링크로 변환됩니다.
