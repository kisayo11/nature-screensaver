## 1. 개요 및 대상자별 요약

네이처 화면보호기는 요양병원 인증평가 준비 및 원내 주요 공지를 자동으로 전달하는 스마트 디스플레이 시스템입니다.

* **원무과/간호부 슬라이드 관리자:** 웹 브라우저에서 파워포인트 이미지를 드래그하여 올리고 **[🚀 전 병원 PC 즉시 배포]** 버튼만 누르면 됩니다.
* **병원 각 부서 PC 사용자:** 최초 1회 설치 프로그램(`NatureScreensaverSetup.exe`)만 실행해 두면 이후에는 신경 쓸 필요 없이 자동으로 최신 슬라이드가 재생됩니다.
* **다중 모니터 환경:** 진료실이나 간호스테이션의 듀얼 모니터에서도 환자 차트(EMR)가 보이지 않도록 모든 화면에 완벽하게 화면보호기가 작동합니다.

## 2. 관리자 웹 사용법 (슬라이드 등록 및 배포)

웹 관리자 주소: **`https://nature-screensaver.vercel.app`**  
*(또는 사내 로컬 개발 서버: `http://localhost:3000`)*

---

### 2.1 관리자 로그인 및 보안 잠금
1. 관리자 웹에 접속하면 **네이처 관리자 인증** 화면이 나타납니다.
2. 비밀번호를 입력하고 **[확인]**을 누릅니다.
   * **초기 비밀번호:** 관리자 안내 전화번호 (`01053884497`)
3. 우측 상단의 **[암호변경]** 버튼을 눌러 언제든지 새로운 비밀번호로 변경할 수 있습니다.
4. 자리를 비울 때는 상단의 **[잠금]** 버튼을 누르면 즉시 보안 잠금 화면으로 전환됩니다.

---

### 2.2 슬라이드 이미지 등록 및 교체

#### 방법 A: 구글 슬라이드(Google Slides) 자동 연동 (가장 추천! ★★★)
1. 구글 드라이브에 **구글 슬라이드(Google Slides)** 문서를 작성하거나, 기존 PPT를 구글 슬라이드로 업로드합니다.
2. 구글 슬라이드 우측 상단 **[공유]**를 클릭하고, 일반 액세스를 **'링크가 있는 모든 사용자(뷰어)'**로 설정한 뒤 링크를 복사합니다.
3. 관리자 웹 상단의 보라색 **[📊 구글 슬라이드 연동]** 버튼을 클릭합니다.
4. 복사한 구글 슬라이드 링크를 입력창에 붙여넣고 **[⚡ 슬라이드 자동 불러오기]** 버튼을 누릅니다.
5. 시스템이 프레젠테이션의 모든 슬라이드를 자동으로 감지하여 고화질 이미지 카드를 일괄 생성합니다. (PPT에서 PNG로 내보낼 필요가 전혀 없습니다!)

#### 방법 B: 파워포인트 이미지 파일 일괄 드래그 & 드롭
1. 파워포인트(PPT)에서 작성한 슬라이드를 **[파일] → [다른 이름으로 저장] → 파일 형식을 `PNG` 또는 `JPEG`**로 선택하여 폴더에 저장합니다.
2. 관리자 웹 화면 중간의 넓은 점선 박스(**📂 PPT에서 내보낸 이미지 파일들을 이곳에 마우스로 끌어다 놓으세요**)에 이미지 파일들을 한 번에 선택하여 마우스로 끌어다 놓습니다.
3. 슬라이드 카드들이 순서대로 자동 생성됩니다.

#### 방법 C: 기존 슬라이드 사진만 1장 교체
* 슬라이드 카드의 **이미지 썸네일 영역을 클릭**하면 파일 선택 창이 열리며 새 사진으로 즉시 교체됩니다.

#### 방법 D: 빈 슬라이드 추가 또는 웹 링크 일괄 추가
* 상단 우측의 **[＋ 빈 슬라이드]** 버튼을 눌러 직접 입력하거나,
* **[🔗 링크 일괄 추가]**를 눌러 이미지 URL을 한 줄에 하나씩 붙여넣을 수도 있습니다.

---

### 2.3 슬라이드 순서 및 재생 시간 설정
1. **순서 변경:**
   * 슬라이드 카드 좌측의 점 6개 아이콘(`⋮⋮`)을 마우스로 잡고 위아래로 끌어서 원하는 위치에 놓으면 자동으로 순서가 재배치됩니다.
   * 또는 카드 우측의 **[▲] / [▼]** 버튼으로 1칸씩 이동할 수 있습니다.
2. **슬라이드 표시 시간 설정:**
   * **전체 기본 시간:** 상단 설정 카드의 `슬라이드 표시 시간`에서 프리셋(5초, 10초, 15초, 20초, 30초)을 선택하거나 초 단위로 입력합니다. (기본 권장: 15초 ~ 20초)
   * **개별 슬라이드 시간:** 특정 슬라이드만 더 오래 보여주고 싶다면 카드 내부의 `표시 시간(초)`에 원하는 초(예: 30)를 입력합니다. (비워둘 시 전체 기본 시간 적용)

---

### 2.4 D-Day 배지 및 하단 공지사항 문구 설정
1. **하단 공지사항 배너 문구:**
   * 화면보호기 하단에 고정 표시될 안내 문구를 입력합니다. (예: `4주기 의료기관 인증평가 대비 원내 집중 교육 기간`)
2. **D-Day 배지 명칭 및 목표 날짜:**
   * **배지 명칭:** 예: `4주기 인증평가`
   * **목표 날짜:** 달력에서 평가 시작일(예: `2026-11-25`)을 선택합니다.
   * 화면보호기 하단 우측에 실시간으로 `🌿 4주기 인증평가 D-49` 형태의 에메랄드 배지가 자동으로 계산되어 표시됩니다.

---

### 2.5 실시간 시뮬레이터로 미리보기
배포하기 전, 실제 병원 모니터에서 어떻게 보이는지 먼저 확인하세요!
1. 상단 메뉴에서 **[화면보호기 미리보기]** 버튼을 클릭합니다.
2. 실제 윈도우 화면보호기와 동일한 비율, 글래스모피즘 상태 바, 시계, D-Day 배지 및 슬라이드 자동 넘김이 동작합니다.
3. `◀ 이전`, `⏸ 일시정지`, `다음 ▶` 버튼으로 슬라이드를 검수한 후 `닫기 ✕`를 누릅니다.

---

### 2.6 전 병원 PC 배포하기 (원클릭)
1. 슬라이드 검수가 완료되면 우측 상단 또는 하단 플로팅 바의 **[🚀 전 병원 PC 즉시 배포]** 버튼을 클릭합니다.
2. 배포 모달이 열리며 5단계 진행 과정이 표시됩니다:
   * 1단계: 슬라이드 및 버전 유효성 검사
   * 2단계: GitHub 원격 저장소 인증
   * 3단계: 신규 슬라이드 이미지 안전 업로드
   * 4단계: 영구 형상 관리 커밋 및 푸시
   * 5단계: Vercel 글로벌 CDN 전송 완료
3. 약 5~15초 내에 **"🎉 전 병원 PC 배포 성공!"** 알림이 표시됩니다.
4. 이제 병원 내 모든 PC는 각자의 동기화 주기에 맞춰 자동으로 새 슬라이드를 다운로드받아 재생합니다.

---

### 2.7 배포 이력 관리 및 원클릭 롤백 (이전 버전 복원)
잘못된 사진을 배포했거나 이전 슬라이드로 되돌리고 싶을 때:
1. 상단 메뉴의 **[배포 이력]** 버튼을 클릭합니다.
2. 과거에 배포했던 버전들의 일시, 슬라이드 수, 공지사항 목록이 표시됩니다.
3. 원하는 버전의 **[이 버전으로 복원]** 버튼을 누르면 1초 만에 해당 시점의 슬라이드 구성으로 복원됩니다.
4. 이후 다시 **[배포하기]**를 누르면 즉시 이전 상태로 병원 PC들에 재배포됩니다.

---

### 2.8 원내 PC 작동 현황 모니터링
1. 상단 메뉴의 **[원내 PC 현황]** 버튼을 클릭합니다.
2. 최근 24시간 동안 화면보호기 신호를 보낸 병원 PC 목록(컴퓨터 이름, 사용자 계정, 모니터 개수, 적용된 슬라이드 버전, 최근 동기화 시각)이 실시간으로 표시됩니다.
3. 정상 가동 중인 PC 대수와 미가동 PC를 한눈에 파악할 수 있습니다.

## 3. 병원 내 PC 설치 및 환경설정 가이드

### 3.1 신규 PC 설치 방법 (1회 설치)
1. **설치 파일 원클릭 다운로드:**
   * **관리자 웹 상단 [📥 설치파일 받기] 버튼 클릭:**
     * 번거로운 NAS 계정 로그인이나 비밀번호 입력 없이, 웹 브라우저에서 **[설치 프로그램 다운로드 (.exe)]**를 클릭하면 바로 받아집니다.
     * 관리자 웹 모달 내에서 구글 드라이브 직링크(뷰어 공개) 또는 원내 NAS 비번 없는 공유 링크로 다운로드 소스를 언제든 유연하게 변경할 수 있습니다.
2. **설치 실행:**
   * 다운로드받은 `NatureScreensaverSetup.exe`를 더블 클릭하여 실행합니다.
   * Windows SmartScreen 파란 경고창이 나타날 경우 **[추가 정보] → [실행]**을 누릅니다.
   * 관리자 권한 창(UAC) 없이 일반 사용자 계정에서도 마법사의 **[설치]** 클릭 한 번으로 10초 내에 설치됩니다.
3. **설치 완료 후 자동 적용 사항:**
   * 윈도우 기본 화면보호기로 `NatureScreensaver.scr` 자동 지정.
   * 화면보호기 대기시간 10분(600초) 자동 설정.
   * 클라우드 배포 서버(`nature-screensaver.vercel.app`)와 30분 주기 백그라운드 자동 동기화 가동.
   * 설치 직후 설정 안내 창이 1회 나타나며 설치가 완료됩니다.

---

### 3.2 윈도우 화면보호기 대기시간 변경 방법
1. 윈도우 시작 메뉴 검색창에 **`화면 보호기 변경`**을 입력하고 실행합니다.
2. 화면 보호기 드롭다운에 `NatureScreensaver`가 선택되어 있는지 확인합니다.
3. **대기(W):** 시간을 원하는 분 단위(예: 10분 또는 5분)로 조절한 뒤 **[적용]** 및 **[확인]**을 누릅니다.

---

### 3.3 설치 파일 및 데이터 저장 경로
* **프로그램 설치 위치:**
  `%LOCALAPPDATA%\Programs\NatureScreensaver`
* **슬라이드 캐시 및 설정 파일 위치:**
  `%LOCALAPPDATA%\NatureScreensaver`
  * `settings.json`: 동기화 서버 주소 (`https://nature-screensaver.vercel.app/config.json`)
  * `last-config.json`: 최근 수신된 슬라이드 목록 및 설정 정보
  * `cache/`: 다운로드된 슬라이드 이미지 파일들 (`.png`, `.jpg` 등)
  * `sync.log`: 동기화 시도 및 다운로드 상세 로그

## 4. 전산 관리자 및 개발자 운영 가이드

### 4.1 로컬 개발 서버 실행
로컬에서 관리자 웹을 수정하거나 테스트할 때:
```powershell
# 프로젝트 루트 디렉토리에서 실행
npm run dev
```
* 브라우저에서 `http://localhost:3000` 접속.
* 로컬 개발 서버(`scripts/dev-server.js`)는 정적 서빙뿐만 아니라 슬라이드 이미지 저장 및 Git 커밋/푸시 로직을 로컬 환경에서 직접 처리합니다.

---

### 4.2 C# 클라이언트 및 인스톨러 빌드
화면보호기 엔진 코드를 수정했거나 새로운 설치 파일(`.exe`)을 생성할 때:
```powershell
# PowerShell 관리자 콘솔에서 실행
.\scripts\build.ps1
```
* **동작 순서:**
  1. `dotnet publish client\NatureScreensaver.csproj` (단일 실행 파일, Self-Contained, win-x64)
  2. 실행 바이너리를 `NatureScreensaver.scr`로 자동 복제
  3. Inno Setup 컴파일러(`ISCC.exe`)를 감지하여 `installer\Output\NatureScreensaverSetup.exe` 생성
* Inno Setup이 미설치된 환경인 경우, GitHub 저장소에 코드를 `git push`하면 GitHub Actions(`.github/workflows/build-screensaver.yml`)가 자동으로 클라우드에서 빌드하여 아티팩트로 다운로드할 수 있습니다.

---

### 4.3 GitHub API 연동 토큰(PAT) 등록 방법
어느 자리에서든 웹 브라우저만으로 GitHub에 자동 커밋하고 배포하려면 GitHub Personal Access Token이 필요합니다:
1. 웹 관리자 상단의 **[📖 1분 토큰 발급 가이드]** 버튼 클릭.
2. 가이드 내 바로가기 링크를 클릭하여 GitHub 토큰 생성 페이지로 이동.
3. `repo` 권한이 체크되어 있는지 확인 후 맨 아래 **[Generate token]** 클릭.
4. 생성된 `ghp_...` 토큰 문자열을 복사하여 웹 관리자 상단의 입력칸에 붙여넣고 **[⚡ 연결 테스트]** 클릭.
5. *(더 안전한 방법)* Vercel 프로젝트 환경변수에 `GITHUB_TOKEN` 키로 등록해 두면 관리자가 토큰을 입력하지 않아도 서버리스 엔드포인트(`api/deploy.js`)가 자동으로 안전하게 배포합니다.

## 5. 자주 묻는 질문 및 문제 해결 (FAQ & Troubleshooting)

### Q1. 새 슬라이드를 배포했는데 병원 PC에 바로 반영되지 않습니다.
* **원인:** 각 PC는 `PC 업데이트 주기`(기본값 10분)마다 서버를 확인합니다.
* **해결:**
  * 즉시 반영을 확인하고 싶다면 해당 PC에서 화면보호기를 해제했다가 1회 다시 작동시키면 기동 즉시 최신 설정을 다운로드합니다.
  * `%LOCALAPPDATA%\NatureScreensaver\sync.log` 파일을 열어 최근 동기화 성공 여부를 확인하세요.

### Q2. 병원 인터넷이 일시적으로 끊기면 화면보호기가 멈추나요?
* **아닙니다.** 네이처 화면보호기는 오프라인 캐시 시스템을 갖추고 있어, 인터넷이 연결되지 않더라도 `%LOCALAPPDATA%\NatureScreensaver\cache` 폴더에 다운로드되어 있던 슬라이드들을 중단 없이 연속 재생합니다.

### Q3. 보조 모니터(듀얼 모니터)에는 화면보호기가 안 뜨나요?
* **정상적으로 뜹니다.** 본 시스템은 듀얼 모니터, 트리플 모니터를 완벽하게 지원합니다. 연결된 모든 모니터에 각각 화면보호기 창이 전체화면으로 실행되어 진료실 및 간호스테이션의 EMR 환자정보 노출을 철저히 방어합니다.

### Q4. 관리자 비밀번호를 잊어버렸습니다.
* 브라우저 개발자 도구(F12) 콘솔(Console)에서 아래 명령어를 실행하면 초기 비밀번호로 리셋됩니다:
  ```javascript
  localStorage.removeItem("natureScreensaverPassword");
  sessionStorage.removeItem("natureScreensaverAuth");
  location.reload();
  ```
  초기 비밀번호는 관리자 안내 번호(`01053884497`)입니다.

### Q5. 화면보호기 동작 중 마우스가 살짝만 건드려져도 꺼집니다.
* 네이처 화면보호기에는 **미세 진동 방어 로직**이 적용되어 있어, 기동 후 1.5초 이내에는 마우스 이동을 무시하며, 20픽셀 이상 유의미하게 움직였을 때만 종료됩니다. 일반적인 사용 환경에서 오작동을 최소화하도록 설계되어 있습니다.
